# Results index

124 report and receipt files accumulated across the campaign. This index
groups them and marks the ones the [README](../README.md) treats as current.

**Reading rule.** Only the files under *Headline results* carry current claims.
Everything else is a supporting receipt, a diagnostic, or a superseded attempt,
retained for provenance. A file being present is not a claim that its result
still stands. Where a report was superseded, the later measurement is in the
README status board and the narrative is in [docs/CAMPAIGN_HISTORY.md](../docs/CAMPAIGN_HISTORY.md).

Files marked `cited` are referenced directly by the README or the campaign history.
